Before you sign anything

Do I need a broker if I can buy a policy directly from an insurer's app?

You can, but you're only seeing that one insurer's product. A broker places the same request across multiple insurers and reads the policy wording for exclusions before you commit — at no extra cost to you.

Can you help if I already hold a policy elsewhere?

Yes — we can review an existing policy at renewal, flag gaps in cover, and place it with a different insurer if that's a better fit, without a lapse in cover.

What happens when I need to file a claim?

Contact us directly and we handle intimation, documentation and follow-up with the insurer through to settlement. See the Claims Advocacy page for the full process.
